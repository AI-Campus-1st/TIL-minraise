## 문항1. 모음은 몇 개나 있을까?
> 문자열이 주어졌을 때, 해당 문자열의 모음 갯수를 계산하는 코드를 작성하시오.

### 정답
```py
word1 = 'apple' # => 2
word2 = 'banana' # => 3

print(word1.count('a') + word1.count('e') + word1.count('i') + word1.count('o') + word1.count('u'))
print(word2.count('a') + word2.count('e') + word2.count('i') + word2.count('o') + word2.count('u'))
```


## 문항2. 네모 출력
> 두 개의 정수 n과 m이 주어졌을 때, 가로의 길이가 n, 세로의 길이가 m인 직사각형 형태를 별(*) 문자를 이용하여 출력하시오.  
> 단, 반복문은 사용할 수 없다.

### 정답
```py
n = 5
m = 9

print(('*' * n + '\n') * m)
```

## 문항3. Built-in 함수와 메서드
> sorted()와 .sort()의 차이점을 코드의 실행 결과를 활용하여 설명하시오.

### 정답
```py
numbers = [5, 4, 3, 2, 1]

print(sorted(numbers))
print(numbers)

=>
[1, 2, 3, 4, 5]
[5, 4, 3, 2, 1]

numbers.sort()
print(numbers)

=>
[1, 2, 3, 4, 5]

# sorted() : 정렬된 리스트를 반환하고, 원본은 변경되지 않는다. 
# .sort() : 원본 리스트 자체를 정렬하며, 원본이 변경된다.
```
